Platform: Laravel 12 Full-Stack — Blade — Bootstrap 5

Deployment: Simulasi lokal dengan HTTPS Ngrok
Tanggal: 19 November 2026

URL demo: https://stroller-dowry-expulsion.ngrok-free.dev

Tautan demo bergantung pada server Laravel dan proses tunnel Ngrok yang masih aktif.

1. Ringkasan Eksekutif

Aplikasi ini mendukung tiga role: Mahasiswa, Guru/Dosen, dan Admin. Fitur utama meliputi autentikasi berbasis session, pengelolaan tugas personal, aktivitas belajar, tugas akademik dan progres, enrollment, mata kuliah, notifikasi in-app, dashboard, serta tema Light/Dark.

Status verifikasi: aplikasi berjalan melalui Laravel local server; Ngrok menyediakan akses HTTPS; Playwright berhasil mengambil seluruh screenshot; dan 135 test otomatis lulus dengan 564 assertion pada 19 November 2026.

3. Arsitektur Sistem

Browser → Ngrok HTTPS → Laravel Web Routes → Middleware / Policy
→ Controller → Form Request / Service → Eloquent → MySQL

Alur deployment simulasi

  1. Menjalankan aplikasi Laravel lokal pada port 8000.
  2. Menjalankan Ngrok untuk meneruskan trafik HTTPS ke localhost.
  3. Laravel memproses session, CSRF, middleware role, policy, dan request aplikasi.
  4. Data dibaca atau ditulis melalui Eloquent ke MySQL.
  5. Playwright mengakses halaman melalui domain Ngrok dan mengambil screenshot.

5. Keamanan

  • Autentikasi: password di-hash dengan fasilitas Laravel; login menggunakan username dan password.
  • Otorisasi: middleware role serta Policy/Gate untuk resource utama.
  • CSRF: semua form mutasi dilindungi token CSRF.
  • Rate limit login: lima percobaan gagal per menit.
  • Akun nonaktif: ditolak dan sesi yang aktif dihentikan.
  • Password sementara: kedaluwarsa 72 jam dan wajib rotasi.
  • Cookie: hasil Playwright membuktikan cookie sesi bertanda Secure, HttpOnly, dan SameSite=Lax.
  • Optimistic locking: row_version pada resource yang ditentukan.

8. Cara Menjalankan dan Memperpanjang Demo

  1. Masuk ke folder proyek.
  2. Konfigurasi `.env`, jalankan migration dan seeder:
    php artisan migrate
    php artisan db:seed
  3. Jalankan aplikasi:
    php artisan serve --host=127.0.0.1 --port=8000
  4. Jalankan tunnel pada terminal lain:
    ngrok http 8000
  5. Salin URL HTTPS dari Ngrok ke `APP_URL`, kemudian jalankan php artisan config:clear.
  6. Ambil screenshot ulang:
    BASE_URL=https://domain-ngrok.node tests/e2e/capture-screenshots.mjs

16. Kesimpulan dan Keterbatasan

Kesimpulan: implementasi Phase 0–8 dapat dijalankan dan didemonstrasikan. Tiga fitur utama, otorisasi role, HTTPS, dan screenshot bukti telah tersedia.
  • Deployment menggunakan Ngrok, bukan VM OCI produksi.
  • URL hanya aktif selama server Laravel dan tunnel aktif.
  • Tidak ada bukti deployment Nginx/PHP-FPM/MySQL pada satu VM OCI.
  • WebKit/Safari belum diuji karena keterbatasan host.
  • Backup eksternal dan restore produksi belum dilakukan.
